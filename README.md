# 📝 한장 — 누구나 쉽게 만드는 A4 학습지

클릭 몇 번이면 **2022 개정 교육과정에 맞는 A4 학습지와 정답지**가 완성됩니다.
학부모, 컴퓨터가 익숙하지 않은 선생님도 쓸 수 있도록 **한 화면에 한 가지씩** 고르게 만들었습니다.

## 이렇게 써요

**🏠 처음 화면** 맨 위 **💬 말로 주문하기**에 "3학년 수학 덧셈과 뺄셈이랑 국어 발표 관련 내용으로 만들어 줘"처럼 적으면
AI가 학년·과목·배울 내용을 골라 둡니다. 골라 둔 화면에서 확인만 하고 만들면 돼요.
(과목을 여러 개 말하면 한 장에 과목별로 나눠 담고, "엮어서", "프로젝트로"라고 하면 융합 과제로 만들어요.)

직접 고르려면 큰 카드 3개 중 하나를 누릅니다.

| 카드 | 순서 |
|---|---|
| 📘 **한 과목 학습지** (처음이라면 여기) | ① 학년·과목 → ② 배울 내용 → ③ 꾸미기 → ④ 완성 |
| 🔗 **여러 과목 융합 과제** | ① 학년·과목 2~3개 → ② 꼭 넣을 내용(선택) → ③ 과제 형태·주제·꾸미기 → ④ 완성 |
| 📂 **내 자료로 만들기** | 파일·글로 / 마음에 드는 학습지 따라 만들기 / 빈 학습지에서 직접 / 저장한 학습지 열기 |

- **② 배울 내용**: 영역 버튼을 눌러 가며 체크합니다. 여러 영역에서 골라도 모두 남고, 오른쪽 🧺에 모입니다.
  내용마다 **학부모용 쉬운 설명**과 **배우는 학년·학기**가 함께 나옵니다.
- **③ 꾸미기**: 난이도·문제 수·정답지·학습지 모양을 고릅니다. 모양은 **예시 학습지를 보고** 고릅니다.
- **④ 완성**: 큰 미리보기 위에 **💾 저장하기 · 🖨️ 인쇄하는 법 · 🔄 다시 만들기 · ➕ 새 학습지**가 있습니다.
  왼쪽에서 **✏️ 내용 고치기**(칸마다 **✨ AI 도움**: 더 쉽게·어렵게·다른 문제로·정답 채우기), **🎨 모양 바꾸기**를 할 수 있습니다.

주소 끝에 `?mode=single`, `?mode=fusion`, `?mode=tools`를 붙이면 그 화면으로 바로 열립니다.

## 학습지 유형 (짜임새가 달라요)

| 유형 | 짜임새 |
|---|---|
| 📘 기본 학습지 | 개념 정리 → 문제 → 스스로 점검 |
| 📝 단원평가지 | 2단 시험지, 점수 칸, 문항별 배점(100점), 선택형·단답형 위주 |
| 🧮 연습 문제지 | 짧은 문제를 격자에 촘촘히, 묶음마다 '맞힌 개수' 칸 |
| 🗂 개념 정리 노트 | 코넬 노트: 왼쪽 핵심어 · 오른쪽 빈칸 설명, 마지막 한두 문장 정리 |
| 🔍 탐구·활동지 | 탐구 질문 → 예상 → 조사 방법 → 빈 기록표 → 그리기 → 결론 |
| 🎲 놀이 학습지 | 문제 카드를 풀고 빙고판에서 정답 찾기 (빙고판은 정답과 오답을 섞어 프로그램이 만듦) |

3단계 '꾸미기'에서 예시를 보고 고릅니다. 완성 화면 **🎨 모양 바꾸기 → 📋 학습지 유형**에서 배치만 바로 바꾸거나, 그 유형으로 다시 만들 수 있어요.
"말로 주문하기"에 "단원평가로", "빙고 놀이로"처럼 적어도 됩니다.

## 학습지 모양 (6가지 + 직접 저장)

| 모양 | 특징 |
|---|---|
| 기본 | 깔끔한 기본 |
| 교과서형 | 명조체·가운데 제목, 문항 사이 구분선 |
| 활동지형 | 검은 띠 소제목, 회색 카드 문제 |
| 시험지형 | 쪽 테두리, 칸 나뉜 머리말, 촘촘하게 |
| 저학년 놀이형 | 둥근 이름표·테두리, 아이콘 소제목, 큰 글씨 |
| 노트형 | 공책 여백선, 번호 소제목 |

모양은 정해진 선택지(머리말·소제목·문항 번호·문항 꾸밈·쪽 테두리·아이콘·글자 크기 등)의 조합이라,
어떤 모양이든 A4 인쇄 규격이 깨지지 않습니다. "📂 마음에 드는 학습지 따라 만들기"로 가져온 모양도 저장해 두고 씁니다.

## 내 학습지 양식에 넣기

마음에 드는 학습지 **양식(한글 HWPX·PDF·사진)** 을 올리면, 🟦 머리(제목·이름 칸·공부할 내용) / 🟥 문제 자리 / 🟩 꼬리('※ 안내')로 나누고,
머리·꼬리는 그대로 둔 채 문제 자리에 새 문제를 **그 양식 모양**(번호·칸 색·답 줄)으로 넣습니다. 문제가 많으면 쪽이 이어집니다(쪽 수 제한 없음).

1. 꾸미기 단계나 완성 화면에서 **📄 내 학습지 양식에 넣기** → **➕ 새 양식 올리기** → 파일 올리기 → **✨ 양식 살펴보기**
2. **✏️ 양식 나누기·글·모양 고치기**에서 단계마다 고칠 수 있어요.
   - **① 나누기**: 머리·꼬리가 어디까지인지 고릅니다.
   - **② 머리·꼬리 글**: 제목 칸에는 학습지 제목이, '공부할 내용·학습 목표' 칸에는 학습 목표가 자동으로 들어가요. 학년·반, 안내 문구도 직접 고칠 수 있어요.
   - **③ 문제 자리 모양**: 짜임(줄 공책형 / 표형 / 상자형), 번호 모양, 번호 칸 색, 테두리·답 줄 색, 답 줄 간격. 답 줄 수는 '내용 고치기'에서 문항마다 정해요.
3. **💾 이 양식 저장해 두기**로 다음에도 바로 고를 수 있어요.

파일마다 읽는 방법이 다릅니다.

- **한글(HWPX)** — 가장 정확해요. AI 없이 파일의 짜임(표·칸 크기·테두리·칸 색·글꼴·그림)을 그대로 읽어 HTML로 다시 그립니다. 나누는 곳은 조각 목록에서 고릅니다.
- **PDF·사진** — AI가 첫 쪽을 살펴 나누는 곳과 머리의 글을 찾고, 선 색·굵기·답 줄 간격·칸 색은 프로그램이 그림에서 잽니다.
  머리·꼬리는 원래 그림 그대로 쓰고, 고친 글만 원래 글 자리를 바탕색으로 덮고 새로 써요. 나누는 곳은 막대로, 글 자리가 어긋나면 📐로 옮깁니다.
  여러 쪽 PDF는 첫 쪽 모양을 씁니다. 양식 여러 쪽을 그대로 되풀이하고 싶으면 올릴 때 **예전 방식(쪽 그림 위의 칸에 그대로 넣기)** 을 고르세요.
- **옛 한글(HWP)** — 안에 든 첫 쪽 미리보기 그림만 읽을 수 있어 흐릴 수 있어요. 한글에서 **다른 이름으로 저장 → HWPX**로 바꿔 올려 주세요.

## 실행 방법 (Windows)

1. [파이썬](https://www.python.org/downloads/)을 설치합니다(**Add python.exe to PATH** 체크).
2. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 받아 `.env` 파일에 `GEMINI_API_KEY=키`로 저장합니다.
   (앱 왼쪽 ⚙️ 설정에 직접 넣어도 됩니다.)
3. `run.bat`을 더블클릭합니다.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m streamlit run app.py
```

## 배포하기 (키는 쓰는 사람이 각자)

Gemini API 키는 **쓰는 사람마다 자기 것**을 넣습니다([무료 발급](https://aistudio.google.com/apikey)). 키가 없으면 첫 화면에 받는 방법이 나와요.

- **포터블판** (설치 없이 압축만 풀어 쓰기, 윈도우): `.venv\Scripts\python.exe tools/build_portable.py <python-3.12.x-embed-amd64.zip>`
  → `dist/한장_포터블.zip`. 받는 사람은 압축을 풀고 `한장 실행`을 더블클릭합니다(검은 창 없이 주소창 없는 한장 창이 열리고,
  창을 닫으면 저절로 꺼져요). `바탕화면 바로가기 만들기`로 아이콘을 둘 수 있어요. 키는 '💾 이 컴퓨터에 키 기억하기'로
  그 컴퓨터의 `app\.env`에만 저장돼요. 파이썬 '임베디드' 파일은 python.org에서 `.venv`와 같은 버전(3.12)으로 받습니다.
- **인터넷판** ([Streamlit Community Cloud](https://share.streamlit.io), 무료): 이 폴더를 GitHub 저장소에 올리고 `app.py`로 앱을 만듭니다
  (고급 설정에서 Python 3.12). 비밀 값(Secrets)은 넣지 않습니다. 인터넷판에서는
  - 키를 서버에서 읽지 않고, 각자 넣은 키는 그 브라우저 창에서만 쓰여요(서버에 저장 안 함).
  - 양식·모양을 서버에 저장하지 않고 **내 컴퓨터로 내려받기**·**파일 열기**로 대신해요(다른 사람에게 보이지 않게).
- 이 컴퓨터에서 혼자 쓰는 실행(`run.bat`, 포터블)만 `HANJANG_LOCAL=1`을 주어 키 기억하기·양식 저장을 켭니다.
  그 표시가 없으면 언제나 인터넷판처럼(안전하게) 동작합니다.

## 정확성 (학년·교육과정에 맞게)

1. **학년 범위**: 고른 성취기준을 그 학년에서 어디까지 배우는지, 아직 배우지 않은 내용이 무엇인지 교육과정 데이터에서 뽑아 AI에게 줍니다.
   (예: 4학년까지는 분수를 약분하지 않음, 3학년 곱셈은 (세 자리)×(두 자리)를 쓰지 않음)
2. **프로그램 검산**: 계산 문제(비례식, 큰 수 읽기·쓰기 포함)의 정답을 프로그램이 다시 계산해 틀리면 고칩니다.
   보기가 겹치거나, 빈 표를 보라고 하거나, O/X 문제에 정답이 적혀 있는 것도 프로그램이 찾습니다.
3. **AI 검토**(기본 켬, 20~40초 더): 다 만든 뒤 AI가 문항을 다시 풀어 보고, 틀린 정답·학년에 맞지 않는 내용·답이 애매하거나
   자료가 빠진 문항, 개념 설명의 틀린 내용을 고칩니다. 고친 내용은 완성 화면 **🔍 검토하며 바로잡은 것**에서 볼 수 있어요.

그래도 AI가 만든 학습지이므로, 아이에게 주기 전에 한 번 훑어봐 주세요.

## AI 속도와 정확성
- 기본 모델 **gemini-3.5-flash-lite**(빠름) + "많이 생각하기". 실측(2026-10) 학습지 1장 **약 20~30초**.
- 고른 모델이 붐비면 100초 안에 다른 모델로 바꿔 다시 만듭니다. 무료 키는 모델별 하루 사용 횟수 제한이 있습니다.
- AI가 만든 내용이므로 아이에게 주기 전에 문제와 정답을 한 번 확인해 주세요.
